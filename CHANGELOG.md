# Changelog

All notable changes to Workboard for Hermes. Newest on top.

## 0.1.0 (2026-11-24)

- First release: your Jira board inside Hermes Desktop.
- **Board view**: the board's own columns and status mapping, your tickets in
  its open sprints, Done limited to the last N days (default 7).
- **Focus view**: what's in flight, an activity feed (column moves from Jira's
  history plus notes the agent left), and a compact rest-of-board.
- Asana tasks under both views (optional).
- Ticket drawer with description, subtasks and comments.
- Agent tools: `workboard_board` (read the board) and `workboard_note` (leave
  "built, PR #212 open" on a card).
